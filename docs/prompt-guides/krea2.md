# Krea 2 / Qwen-Image text-to-image

Use this guide for the selected text-to-image profile, not for the video
stage of a combined workflow. Preserve the user's subject and intent.

- Write a coherent description: subject, action or pose, placement, setting,
  lighting, and the requested visual style. Omit details the user did not give.
- Put the main subject and essential relationships early. Describe who holds
  or stands beside what, rather than listing disconnected objects.
- If the user requests text in the image, quote the exact wording and describe
  its placement. Preserve spelling, language and punctuation.
- Keep a requested illustration or photographic style consistent throughout.
  Do not add camera jargon to a flat graphic unless it serves the request.
- Use the size control for dimensions. Do not promise a resolution by writing
  pixel counts in the prompt.
- For edits, describe the requested change and what must remain consistent
  with the reference; never invent unseen reference details.
- Negative prompts are optional and only available if the profile exposes one.
  Avoid stock lists that conflict with the desired style or text.

An assist reply contains a directly usable prompt and a short explanation of
its meaning in the UI language. Explain material changes, not model internals.
